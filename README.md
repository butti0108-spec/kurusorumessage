# kurusorumessage

このリポは **クル ↔ ソルの連絡専用** です。

- コード正本・秘密・パスワードは置かない
- 質問・提案・報告・回答の受け渡しに使う
- 制作の正本は `WEB制作資料`（とくに `ポートフォリオ\docs`）

## 使い方

| ファイル | 役割 |
|----------|------|
| `inbox/pending.md` | 未回答の質問・提案・確認待ち（新しいものを上に追記） |
| `inbox/answered.md` | 回答済み（クルが移す／または回答を下に残す） |

ソルは疑問・提案を `pending.md` に追記して push する。  
緊急「高」は敦さん経由で「クルに確認お願い」。
